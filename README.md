# Small-Office-Network

🌐 **Small Office Network Design & Implementation Using Cisco Packet Tracer**

## Overview

Designed and simulated a small office network using Cisco Packet Tracer, connecting HR, Sales, and IT departments through a structured and secure network infrastructure. The project focuses on VLAN segmentation, inter-VLAN communication, IP addressing, and switch port security.

## Objectives

To build an organized, secure, and functional office network that enables communication between departments while maintaining network segmentation and controlling unauthorized device access.

## 🛠️ Key Stages & Techniques

✅ **VLAN Configuration**

Created separate VLANs for HR, Sales, and IT to organize the network and isolate departmental broadcast domains.

✅ **IPv4 Addressing**

Configured IP addresses, subnet masks, and default gateways for end devices and the server.

✅ **802.1Q Trunking**

Configured trunk links to carry multiple VLANs between network devices, with a dedicated native VLAN.

✅ **Inter-VLAN Routing**

Implemented Router-on-a-Stick using router subinterfaces to enable communication between different VLANs.

✅ **Port Security**

Applied sticky MAC address learning, limited the number of permitted MAC addresses, and configured violation shutdown to restrict unauthorized device connections.

✅ **Unused Port Security**

Assigned unused switch ports to a dedicated VLAN and administratively disabled them to reduce unauthorized access risks.

✅ **Network Verification & Troubleshooting**

Verified VLAN assignments, trunk operation, MAC address learning, port security, and connectivity using Cisco IOS commands and ping tests.

## 🎯 Project Outcomes

✅ Structured departmental network segmentation

✅ Communication between different VLANs

✅ Organized IPv4 address allocation

✅ Improved switch port security

✅ Secure management of unused switch ports

✅ Verified network configurations and connectivity

## 🎓 Project Context

A practical networking project developed using Cisco Packet Tracer to apply CCNA concepts in network design, switching, routing, and basic network security. The project demonstrates hands-on experience in configuring and verifying a small office network infrastructure.
